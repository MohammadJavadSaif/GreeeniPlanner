// readme.html · v1.5.0

Plant a goal. Watch it branch.
Don't water it with vague intentions.

Most goal-tracking apps want you to feel like you're filling out a tax form. GreeniPlanner wants you to feel like you're running a small, well-organized, slightly intimidating garden — local-first, offline-ready, no accounts, no cloud lock-in, and no subscription.

01What's New in v1.5.0
Releases
Android, Windows & macOS Installers. Automated GitHub Actions workflow builds and publishes native packages for Android (.apk), Windows (.exe NSIS & .msi), and macOS Universal (.dmg & .app.zip) directly to GitHub Releases.
Updates
Seamless In-Place Android Upgrades. Persistent APK release signing and a monotonically increasing versionCode let you install new versions directly over previous ones without uninstalling or losing any app data.
Bilingual
Persian (فارسی) & Full RTL Layout. Switch between English and Persian (with automatic system language detection) and full Right-to-Left layout across every view, plus Light / Dark / System appearance modes.
Ledger
Expense Boards & Debts/Credits (D&C). Track Weekly and Monthly expenses alongside dedicated Debts & Credits lists for money owed and money owed to you.
Alerts
Native System Notifications & Backup. Daily ToDo reminders integrate with Android's native NotificationManager and Service Worker notifications, plus full JSON backup & restore in Settings.
02The Hierarchy

Goals and Tasks live in dedicated spaces. Your Goal tree grows from Long-term to Medium-term and Short-term goals. In the separate Tasks space, actionable Tasks (and nested Sub-tasks) can be linked back to any level of your Goal tree.

Goal Tree Space
Long-term GoalRun a marathon by 35
└─ Medium-term GoalSub-3:30 in the next 18 months
└─ Short-term GoalFinish a half marathon this spring
Tasks Space (Separated)
TaskBuild a 12-week training block (Linked to Short-term Goal)
└─ Sub-taskBuy proper running shoes

Toggle the ↕ sorting button in any room header to drag and reorder items within their group.

03The Six Rooms
🗂️

1. Goals — the long game

Plant Long, Medium, and Short-term goals (⌘1). Live statistics modal, collapsible branches, and instant filtering.

✅

2. Tasks — the breakdown

Dedicated tab (⌘2) for Tasks and Sub-tasks. Link tasks to goals, set priorities, and auto-calculate duration from start/end dates.

☀️

3. ToDos — the right-now

7-day interactive date strip (⌘3). Four daily mood priorities, native OS reminder notifications, and one-click Copy/Move between days.

↻

4. Routines — the repeat

Recurring daily habits starting from a chosen date. Check off per day, edit for a single day only, or skip for one day without touching other days.

📝

5. Notes & Lists — the scratchpad

Rich-text Notes and interactive Checklists (⌘4). Pin important cards to the top and search instantly with ⌘F or /.

💳

6. Expenses & D&C — the ledger

Weekly and Monthly expense boards plus dedicated Debts & Credits (D&C) lists (⌘5) with multi-currency and net balance stats.

04What Every Branch Holds
Name *
Required across all items. Vague intentions don't get a slot.
Description
Optional context displayed cleanly beneath the card title.
Timeframe
Three side-by-side boxes: Year / Month / Day. Required for goals, auto-calculated or manual ("Duration") for tasks.
Dates & Reminders
Multi-calendar date picker (Gregorian, Shamsi, Hijri) plus custom 12-hour reminder time picker for ToDos and Routines.
Debts & Credits
Each D&C entry tracks Name, Amount, Type (Debt / Money Owed or Credit / Owed to You), optional Date, and settled state.

06Cross-Platform Installers
Android (.apk)
Universal APK (GreeniPlanner_1.5.0_android_universal.apk) signed with a persistent release certificate and monotonic versionCode. Install directly over older versions to update in place without losing data.
Windows (.exe / .msi)
Includes both GreeniPlanner_1.5.0_x64-setup.exe (NSIS installer with per-user or system-wide setup) and GreeniPlanner_1.5.0_x64_en-US.msi (Windows Installer).
macOS (.dmg / .app)
Universal Binary (GreeniPlanner_1.5.0_universal.dmg & .app.zip) running natively on both Apple Silicon (M1–M4) and Intel Macs. On first launch, right-click GreeniPlanner.app → Open.
07Keyboard Shortcuts
Navigation & Rooms
Switch Rooms⌘1–⌘5 / Alt+1–5
Jump to Goals (1), Tasks (2), ToDos (3), Notes (4), or Expenses (5).
Cycle RoomsTab / Shift+Tab
Cycle forward or backward across topbar rooms.
Daily StripT / [ ] / D
Jump to Today (T), shift week ([ ]), or pick date (D).
Actions & Controls

Open the creation modal for the currently active room.

Cycle Light/Dark/System theme or Gregorian/Shamsi/Hijri calendar.
Search & Help
Focus search (⌘F / /) or open Shortcuts Guide (? / F1).
08Worth Knowing
